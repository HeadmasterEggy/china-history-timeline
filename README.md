# 华夏历史长卷

一个可视化中国历史的单页网页：从夏朝（约前2070年）到今天，按真实年份比例把 52 个政权排在一条可拖动、可缩放的时间长卷上，并列泳道表示同一时期并存的政权（如三国、南北朝、宋辽金夏）。

功能：
- 全景缩略条，点击或拖动快速跳转
- 缩放（也可 Ctrl/⌘ + 滚轮），时代快速定位
- 点击任一朝代查看建立者、都城、同期政权、代表人物和大事记
- 搜索朝代、人物或事件
- 键盘 ← → 切换相邻朝代；网址 `#tang` 这类锚点可直接分享某个朝代
- 自动跟随系统浅色/深色模式，手机可用

纯静态页面，直接打开 `index.html` 即可，无需构建。

年代采用通行说法，上古年代均为约数，部分政权起止年存在不同观点。
